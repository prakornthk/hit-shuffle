# วงล้อเพลงฮิต — สุ่มเพลงฮิตประจำเดือน

หน้าเว็บสุ่มเพลงฮิตประจำเดือน เปิดบัตรสุ่มแล้วกดฟังต่อบน YouTube / Spotify

## เปิดใช้งาน

เป็นไฟล์ HTML ไฟล์เดียว ไม่มี build step และไม่พึ่ง backend

```
open index.html        # macOS
```

หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ (`npx serve .` / `python3 -m http.server`) — ไม่มีความต่างในการทำงาน

## ฟีเจอร์

- เลือกเดือนได้ ม.ค. 2024 – ธ.ค. 2025 (24 เดือน รวม 89 เพลงในชุดตั้งต้น)
- สุ่มไม่ซ้ำแบบกองไพ่ — สุ่มจนครบเดือนแล้วจึงหยิบกองใหม่
- บัตรผลลัพธ์พร้อมปุ่ม YouTube / Spotify และปุ่มคัดลอกลิงก์บัตร (แชร์ลิงก์ลึก `?m=YYYY-MM&t=<id>` ได้)
- ประวัติบัตรที่เพิ่งจับ 5 ใบล่าสุด (เก็บใน localStorage)
- คีย์บอร์ด: `Space` = สุ่ม · รองรับ `prefers-reduced-motion` · ใช้งานบนมือถือได้

## แก้ไขชุดเพลง

แก้ array `SONGS` ตอนต้น `<script>` ใน `index.html`:

```js
{ t: "ชื่อเพลง", a: "ศิลปิน", ym: "2025-06", g: "kpop" }  // g: kpop | intl | latin | thai
```

- `ym` คือเดือนที่เพลงฮิตติดชาร์ต (ไม่ใช่วันวางจำหน่าย) — เดือนไหนมีเพลง เดือนนั้นจะโผล่ในแถบเลือกเดือนเอง
- ลิงก์ YouTube / Spotify เป็นลิงก์ค้นหา "ศิลปิน + ชื่อเพลง" บนแพลตฟอร์มโดยตรง จึงไม่มีลิงก์เสีย แต่ถ้าต้องการลิงก์ตรง เพิ่มฟิลด์ url ของตัวเองใน `youtubeUrl()` / `spotifyUrl()` ได้

## หมายเหตุ

ชุดเพลงตั้งต้นเรียบเรียงจากเพลงที่ติดชาร์ตดังในปี 2024–2025 โดยคร่าว ๆ ใช้เป็น seed data แก้ไข/เพิ่มได้อิสระ
